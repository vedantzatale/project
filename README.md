# project

This repository contains a simple interest calculator written as a Bash script.

## Files

- `simple-interest.sh` - reads the principal, annual rate of interest and time period in years, then prints the simple interest.
- `LICENSE` - Apache License 2.0
- `CODE_OF_CONDUCT.md` - Contributor Covenant Code of Conduct
- `CONTRIBUTING.md` - guidelines for contributing

## Usage

```bash
bash simple-interest.sh
```
